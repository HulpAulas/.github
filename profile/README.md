# Hulp Aulas

Plataforma educacional que conecta **alunos** e **professores** em tempo real para aulas particulares sob demanda.

> O professor que você precisa, na hora que você precisa.

A Hulp Aulas torna o acesso ao conhecimento mais ágil e acessível: o aluno escolhe a matéria e encontra professores disponíveis para aprender no momento em que precisa.
